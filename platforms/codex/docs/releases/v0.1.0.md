# vibecheck-linear-jev 0.1.0

vibecheck-linear-jev 0.1.0 is the first release: a coding-agent work ledger backed by Linear whose reports are checked by a Jev-compatible judgment model. It starts from vibecheck-jev 1.0.0.

## Requirements

Bun 1.3.14 or later. There is no Node.js path and no Bash launcher: every MCP server entry and hook runs `bun <plugin root>/runtime/vibecheck-linear-jev.mjs` directly, so the plugin runs on Linux, macOS and Windows wherever Bun runs. A judgment source: set `TYPESAFE_API_KEY` for the hosted service, or configure an open source in `config.jsonc`. When a harness starts the plugin without `TYPESAFE_API_KEY`, the runtime reads it from your interactive shell (not on Windows), bounded to 5 seconds.

## Artifacts

`bun run build:release` writes `vibecheck-linear-jev-claude-plugin-0.1.0.zip`, `vibecheck-linear-jev-codex-plugin-0.1.0.zip`, `vibecheck-linear-jev-muse-plugin-0.1.0.zip`, `vibecheck-linear-jev-antigravity-plugin-0.1.0.zip`, `vibecheck-linear-jev-runtime-0.1.0.tar.gz` and `SHA256SUMS` to `artifacts/`. `bun run verify:release` checks the archives and runs their MCP servers and hooks under Bun.
